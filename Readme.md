# Common Commands for AFD

## Creating a new project

```bash
npx create-vite@latest hello-react -- --template react-ts
```

## To traverse directories in the command line

```bash
cd
```

## Installing Node.js packages

```bash
npm install
```

## Running and NPM Script

```bash
npm run <command>
```

## To terminate a running application

CTRL + C shortcut
